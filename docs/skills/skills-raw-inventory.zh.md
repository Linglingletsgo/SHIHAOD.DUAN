# Skills 原始资料清单

## 文档用途

本文档根据个人口述整理，是 Skills 数据库与公开页面的事实底稿。当前只进行基础去重和逻辑归类，不进行能力等级评定，不把没有明确说过的内容补写为事实，也不要求每一项能力都必须对应案例。

整理原则：

- 保留明确提到的技能、知识、工具、经历和背景。
- 合并意思相同或高度重叠的表达，但尽量保留具体细节。
- 项目名称只在确实提到对应关系时记录。
- 没有明确案例的能力可以只保留能力陈述。
- DJ 只记录为基础知识与设备接触，不表述为会进行 DJ 表演。
- Veo 3.1 只作为 Digital Alchemy 创作时所处的生成式视频技术阶段，不作为工具清单条目。
- 健康、药物和生理科学相关内容只记录为日常信息理解与资料判断，不表述为医疗诊断或专业治疗能力。
- 调研与资源发现只采用合法、合规的公开资料、软件、视频、开源项目与信息渠道表述。
