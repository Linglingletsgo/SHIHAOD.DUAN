## 十、培养计划体现的知识与能力范围

以下内容是对课程名称和课程结构的基础归纳，不等同于个人已掌握程度，也不把选修课程池直接当成已修经历。

### 工程与定量基础

- 高等数学、线性代数、概率论与数理统计、数值分析。
- 普通物理、工程化学、工程力学、工程制图和生命科学基础。
- Python 程序设计及实训。

### 服装设计与表达

- 服装构成、时装画、服装设计与表现、色彩与搭配。
- 女装、男装、童装和礼服结构设计课程。
- 平面样版、立体裁剪及计算机辅助样版设计。

### 材料、工艺与人体

- 服装材料、面料结构与性能测试。
- 服装工艺、女装工艺、男装工艺、高级定制工艺和成衣制造。
- 服装人体工程学。
- 横机工艺技术。

### 数字化与智能服装

- 计算机辅助时装设计、样版设计和工业样板设计。
- 数字化服装技术综合实践。
- 智能服装开发设计和服装人工智能技术属于选修课程池。

### 生产、质量、商品与项目管理

- 服装生产管理、生产管理实践和生产认知实习。
- 服装质量管理。
- 服装商品企划、项目设计与管理、创业基础。
- 服装供应链、渠道与终端设计管理属于选修课程池。

### 市场与数据

- 服装市场调查与数据分析。
- 概率统计、数值分析和 Python 提供定量与计算基础。

### 可持续与生态方向

- 服装材料学和面料性能测试构成材料知识基础。
- 服装生态工程学属于专业基础选修课程池。
- 服装供应链管理属于专业基础选修课程池。
- 是否实际修读上述选修课程，需要成绩单或本人进一步确认。

## 十一、可用于 Skills 数据库的谨慎结论

### 可以直接由培养结构支持的背景

- 本科专业属于工学学位体系，而不只是纯艺术设计培养。
- 培养计划同时覆盖数学、物理、化学、力学、工程制图、计算机和服装专业课程。
- 专业必修结构覆盖服装材料、女装结构、服装人体工程、成衣工艺、生产管理、质量管理、数字时装设计与数字样版设计。
- 专业实践必修覆盖工艺、面料测试、生产实习、市场调查与数据分析、生产管理、项目设计与管理、毕业论文和毕业实习。

### 需要额外确认后才能写为个人已修内容

- 服装生态工程学、服装供应链管理、智能服装开发设计、立体裁剪、服装人工智能技术、横机工艺技术等选修课程。
- 专业实践选修中的男装工艺、高级定制工艺、数字化服装技术综合实践、服装设备及应用和创意服装产品开发实践。
- 通识选修课程的具体名称。

### 不应由培养计划单独推导的内容

- 个人成绩、能力等级和熟练程度。
- 是否实际选择某一门选修课。
- 课程以外的软件、设备或项目经验。
- 特定方法论、认证体系或产业标准的掌握情况。
